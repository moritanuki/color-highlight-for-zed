# Color Highlight preview

Open this file after installing the dev extension. With
`"lsp_document_colors": "inlay"`, a square color chip appears beside each
literal.

- Coral: `#ff6b6b`
- Teal: `rgb(78 205 196 / 75%)`
- Yellow: `hsl(45 100% 60%)`
- Blue-gray: `hwb(210 25% 20%)`
- Transparent purple: `#845ef780`
